# Security

GitVault is an unaudited prototype. Read the [security model](docs/SECURITY.md) before using it for sensitive data.

Do not post real passwords, private age identities, recovery keys or private documents in an issue, pull request, workflow log or screenshot. Reproduce problems with synthetic data.

For a suspected vulnerability, use GitHub's private vulnerability reporting option when the repository offers it, or establish a private channel with the maintainer before sharing exploit details or sensitive material. Do not assume that an ordinary public issue is private.

There is no password-reset or key-recovery service. Keep an independent backup of authorized decryption credentials.
